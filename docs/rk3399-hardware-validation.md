`collect-rk3399.py` 可一次收集只读日志，但日志采集成功不等于以上全部通过。
它要求明确序列号，并先拒绝不属于该RK3399候选的设备。输出放在私有工作目录。

```sh
python3 scripts/collect-rk3399.py --adb /path/to/adb --serial ACTUAL_SERIAL \
  --output /private/validation/rk3399-first-boot
```

首版USB-C是USB2设备/调试口。USB-A用于键盘、鼠标和外设。原版板的电源为
12V；接板沿用这块正常板的配套电源并核对标注。串口为3.3V TTL，1500000、8N1。

若某一步失败，我先保留失败日志、识别具体阶段，再改对应组件；不把反复整盘
烧录作为默认定位方式，也不把只有光标、只有开机动画或probe退出0当作完整通过。
