# 儿童乐园与家长模式

我把儿童专区分成「算术练习」「启蒙视频」「学习记录」三个页面，面向家长陪伴的 3–6 岁启蒙。入口是电视首页的「儿童」或「儿童专区」；观看许可、时间和题目范围在「家长设置」中调整。首次设置需要建立 4–8 位数字 PIN，没有出厂默认密码。

## 算术练习

| 模式 | 题目与操作 |
| --- | --- |
| 数一数 | 观察圆点，从三个数字中选择数量 |
| 加法启蒙 | 把左右两组圆点相加，结果不超过设置范围 |
| 减法启蒙 | 从原有圆点中拿走划掉的部分，结果不会为负数 |
| 比大小 | 比较左右两组，选择少于、多于或一样多 |
| 混合练习 | 随机组合上面四种题型 |

默认 10 以内、每轮 5 题；家长可选 5／10／20 以内，以及每轮 5／10 题。圆点直接绘制，不依赖彩色 emoji 字体。题目不计时，答错可以重试；答对后按「下一题」继续，末题按「完成练习」查看结果。方向键移动、确定键选择，也支持鼠标单击。

「学习记录」只保存已完成轮次、完成题数、首次作答正确数以及最近练习模式。首次答错后再答对仍算完成这道题，但不计入首次答对。记录保存在本机，不联网、不上传；中途退出未完成的一轮不计入累计记录。页面重建会恢复当前轮次，完成页重复打开不会重复累计。

**算术练习不扣视频观看时间，也不会增加视频额度。** 即使今日视频时间已用完，仍可练习。与算术分开的原有「视频续看小挑战」保留三题颜色、形状和数数逻辑；它只在本段观看额度耗尽时使用。

## 视频额度与应用许可

默认每段观看 15 分钟、每日累计 60 分钟，完成三题续看挑战后可续看 5 分钟。家长可以调整这些数值。系统计算允许的视频应用及内置短片的前台时间，包括选片时间。到时先停止视频，再进入续看挑战；答题通过返回儿童专区，由家长或孩子重新打开获准的视频。

每日上限不能靠答题增加，重启或开关家长模式也不会清零当日用时。达到每日上限后，继续看视频需要家长通过 PIN 退出家长模式。算术页、学习记录和家长设置不计为视频观看。

「启蒙视频」保留认识颜色、1–5 数数两段原创无配音短片，以及家长选好的第三方视频应用入口。初始第三方许可为空。家长应先在平台内设置儿童模式和分龄，或为 Kodi 准备儿童目录，再允许对应应用。许可控制应用入口和观看时间，不代替平台的内容筛选、账号、会员或地区限制。启动第三方应用前还会重新检查许可和安装状态。

## 返回与家长验证

- 家长模式关闭时，可直接从儿童页返回首页。
- 家长模式开启时，儿童页的返回、Esc 和顶部返回按钮都要求 PIN；取消验证后仍留在儿童页。
- 从算术或续看挑战返回只会回儿童页，不会借此退出家长模式。
- 家长面板离开前台后清除本次授权并关闭 PIN 窗口；重新打开需再次验证。
- PIN 使用独立随机盐和 PBKDF2-HMAC-SHA256；连续五次错误后等待 30 秒。

计时和模式存储在设备保护区的私有 `parental` SharedPreferences；每次使用前最多预记 5 秒。学习进度使用独立的 `kids_progress` 存储。日期只向前推进，回拨时钟不会刷新用时。开机和主页启动会恢复监控；重复启动监控服务不会再次停止正在允许范围内播放的视频。外部视频退出前台或锁屏后会被停止；内置视频离开播放页时释放播放器。

这套实现使用固件的平台签名和系统 UID 来读取前台任务、停止视频应用。家长、儿童和益智 Activity 不向其他应用导出。它面向家庭遥控器使用，USB 调试、刷机和系统文件修改不属于 PIN 的管控范围。

## 已验证范围

2026-11-08 的记录分三层：

1. JVM 使用生产逻辑和 Android 接口替身，通过 10,500 道算术题、600 次会话恢复、完成统计幂等、旧挑战重复输入保护，以及家长控制 14,072 条断言。
2. 生产包在原版 RK3288 上完成五种模式各一整轮 5 题：第一题先错再对，最后均显示首答正确 4/5，并可返回；生产家长设置未变更。输入由 Android 自动化注入，没有用实物红外遥控器验收。
3. 单独的验证包在同一设备上验证新建 PIN、后台重入、取消、算术配置、三种返回门禁、练习不计视频额度和内置视频计时。它使用独立包名与偏好目录，不验证或改写已有生产 PIN。

这些结果不等于全部第三方儿童内容、所有遥控器、跨日/断电实机持久化以及所有超时场景均已通过。测试替身中的写入失败验证也不等于真实存储断电验证。完整证据说明见 [儿童算术与功能验证-20261108.md](儿童算术与功能验证-20261108.md)。

## 开发与复测

生产代码位于 `device/firefly/rk3288/tv/src/org/firefly/tv/`：儿童入口是 `KidsActivity`，算术由 `ArithmeticPractice`、`ArithmeticRound`、`KidsProgress` 实现；观看额度和门禁由 `ParentalPrefs`、`WatchBudget`、`WatchTimeTracker`、`PinDialog` 负责。`PuzzleActivity` 将算术练习与三题续看挑战分开。

在仓库根目录运行：

```bash
python3 scripts/test-arithmetic.py \
  --jdk /path/to/jdk21 \
  --report records/arithmetic-host-tests.json
python3 scripts/test-parental.py \
  --jdk /path/to/jdk21 \
  --report records/parental-host-tests.json
```

主机测试不能代替屏幕与设备验收。修改布局后应检查目标分辨率下标题、圆点、选项和底部按钮；修改生命周期或计时后，应独立检查后台返回、PIN 取消、视频结束和额度用尽。
