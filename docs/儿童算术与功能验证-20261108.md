# 儿童算术与功能验证记录：2026-11-08

我在这次电视界面重构中加入面向 3–6 岁启蒙的儿童乐园，并把主动算术、视频观看和家长管理分开验证。这份记录区分生产包实板、独立验证包、主机逻辑测试与构建检查，不把打开页面当成里面所有业务通过。内容已经脱敏，不记录真实网络地址、无线名称、硬件地址、账号或 PIN。

## 实现与版本

算术包含数数、加法、减法、比较大小和混合五种模式。默认 10 以内、每轮 5 题；家长可设置 5／10／20 以内与 5／10 题。图形数量提示、错误重试、下一题和完成统计均为本地实现。

我保留原有三题续看挑战。主动练习不会扣除或增加视频额度；学习统计使用独立 `kids_progress` 偏好，视频许可、PIN 和观看时间仍在 `parental` 偏好。

我使用包名 `org.firefly.tv.validation` 的独立验证包，避免为了测试清空或改动家庭现有 PIN、许可和观看额度。它不注册为桌面，与生产包使用不同数据目录。家长验证包来自 v1 同源快照，复制时 31 个 Java 文件和资源散列一致，仅 Manifest 的包身份、持久属性和桌面入口改变；v2 仅调整算术标题区。`fixture-device-v4` 指第四轮家长测试，并不是最终桌面 v4 APK。结果确认生产家长偏好未变化，不能写成“用户当前 PIN 已验证”。

算术下一题使用显式按钮并延迟启用；首答统计只计第一次选择，错误可重试；完整轮次按身份去重。原续看挑战加入新题冷却和失效回调保护，活动复用时按用途重建页面。这些主机检查覆盖逻辑，完整实机超时挑战、真实进程死亡、全部生命周期和断电恢复仍未逐项完成。

## 无线与第三方应用的边界

Wi-Fi 已在正常软件重启后自动初始化，框架真实扫描得到 8 个热点，其中 2.4 GHz 为 6 个、5 GHz 为 2 个。TvSettings v3 已安装，有线连接时能显示真实无线列表。安全热点的空密码编辑页可进入，三下 Back 正常退出；添加网络编辑页可取消；快速连接二维码实际渲染并可返回；WLAN 关闭再开启后真实列表恢复，全程保留有线链路。没有填写网络名称或凭据、没有连接热点，也未用手机实际扫码配网。框架扫描证据见 [无线接入记录](validation/wifi-bringup-20261108.json)。

凭据连接、DHCP、实际传输、冷断电与长期稳定未验证，首次 SDIO 枚举仍由一次受限自动恢复处理，不能称上电时序彻底修好。热点/P2P/蓝牙也未声明通过。

SmartTube、Kodi、哔哩小电视、酷喵、Clash、BV 和奇异果的启动记录只确认当时前台包匹配。奇异果历史动态插件发生过资源异常；安装主包与官方包一致，并有插件回退记录。回退后约 45 秒启动、前后台观察无新增崩溃、进程未重启，这仍不覆盖长期插件更新、账号、支付、会员或内容播放。
