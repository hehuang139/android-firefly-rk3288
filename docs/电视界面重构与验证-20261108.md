# 电视界面重构与验证记录

日期：2026-11-08。本文记录我重新设计 Firefly TV 主页、应用、设置、儿童页面和
直播选台的过程。目标是形成适合电视观看距离、遥控器和鼠标的统一体验。

第三版已安装，并通过下文列出的截图与实际操作验收。完整家长控制状态
组合、其他分辨率和长期体验尚未验收；包含本轮 UI 的完整整盘镜像也未更新。
公开构建与开发板实际安装包分别记录，避免把不同内容版本混为同一工件。

## 我为什么重新做

旧版已经能启动应用、看直播和进入家长设置，但视觉上仍像一组开发工具：
大量尺寸相近的灰色按钮、偏小的图标、重复的说明文字占据主要位置。
首页没有充分利用最近观看的频道和应用自身的形象，焦点、正在播放、收藏
等状态也缺少足够清楚的层次。仅修改圆角或换一套颜色不能解决这些问题。

我参考主流电视界面的大幅内容区、横向应用栏、明确焦点和简短导航，重新
分配页面空间。Apple TV 是体验方向的参考，不是本项目已达到相同成熟度的
证明；真正的验收仍要看实际屏幕、输入行为和连续使用结果。

## 我怎样组织主页

主页采用接近黑色的背景、低饱和面板、白色主要文字和灰色辅助信息。
顶部保留导航、时间和连接状态；主要区域显示实际最近观看频道，提供
继续播放和浏览频道两个入口。下方用已安装应用的横幅组织应用栏，快捷
频道来自当前频道表、最近观看和收藏，不加入不存在的推荐节目。

我使用静态地球极光照片提供视觉背景，并在绘制时叠加暗色渐变保证文字
可读。它只是背景，不代表当前频道、节目封面或实时画面。图片来源是
NASA 的 ISS072E159172，归属、原始地址和使用说明记录在
[ARTWORK.md](../device/firefly/rk3288/tv/ARTWORK.md)。应用横幅和图标从已安装
软件包读取；缺少横幅时退回真实应用图标，没有把第三方宣传图复制进仓库。

这次没有加入循环背景视频、实时模糊或持续运动的装饰。RK3288 的播放链路
此前已经暴露过性能问题，界面的动效应该帮助辨认焦点，不能增加持续的
后台绘制负担。静态背景与短时动画是本轮的实现选择，仍需实板确认开销。

## 焦点与鼠标需要同时成立

我把共享组件的焦点统一为白色描边、轻微缩放和短动画。普通卡片使用
180 毫秒过渡；选台行使用 160 毫秒焦点过渡，面板使用 180 毫秒入场。
放大后的卡片需要预留空间，滚动视口仍保留裁切，避免内容越过页头。

旧式触摸焦点行为会让鼠标第一次点击只获得焦点，第二次才执行。
共享交互组件改为不在触摸模式中索取焦点，同时保留方向键焦点和鼠标悬停
反馈。实板已验证首页应用首次点击、应用网格方向键滚动和焦点显示。

返回也属于交互设计。子页面的可见返回入口调用已有返回处理，儿童页继续
经过家长退出逻辑。主页保留返回拦截，避免从主页意外退出到空白页面；
实板已分别验证 Back 与 Escape 在主页保持不退出。

## 直播选台如何保留熟悉的电视操作

我把选台器整理成左侧浮层：顶部是地区与类型两个分段入口，窄栏显示
分类，主栏显示频道编号、名称和实际节目资料。正在播放、焦点和收藏使用
不同状态表达，底部保留操作提示。频道身份和原始索引继续来自同一频道表，
地区与类型只是查看方式，不能因为重排界面而把播放或收藏指向另一台。

地区保留央视及省份组织，类型继续支持新闻、儿童等交叉分类。没有节目单
时显示缺失状态，不根据频道名生成看似真实的节目名称。点击画面或浏览
入口可以打开选台器，返回或 Escape 用于收起；面板外点击也可关闭。

这一轮重构不新增或重新认证频道地址，不改变已有的内置播放路线。
之前的逐频道短测和福建持续播放记录仍有各自版本与观察窗口，不能因为
界面更新就把旧证据写成新版所有频道已经重新通过。频道证据见
[全国频道逐项验证](全国频道逐项验证-20261108.md) 和
[福建频道专项复盘](福建频道专项复盘.md)。

## 其他页面如何统一

| 页面 | 本轮实现 | 保留的使用约束 |
| --- | --- | --- |
| 应用 | 四列横幅卡片，标题放在图片下方，按应用名称组织 | 入口对应实际已安装应用；缺少横幅时使用图标 |
| 设置 | 网络、声音、显示、家长、遥控和应用管理分成清楚的卡片 | 适配 TV 系统设置入口；维护入口保留，重启及刷写模式仍需确认 |
| 儿童 | 原创几何学习卡片与已批准应用横幅，显示剩余时间 | 离线短片存在才显示；第三方入口仍检查家长允许列表 |
| 直播 | 紧凑播放提示和可浏览的分组浮层 | 保留频道身份、收藏、节目单及既有播放器路线 |

儿童页面尤其不能因为增加一个漂亮的返回按钮而绕过原有控制。我保留
打开应用、播放短片、离开页面、家长退出和按键处理的原业务方法；计时
刷新恢复时先移除已有回调，避免重复安排。代码比较能够证明相应方法
未被这轮视觉改写，但不能替代 PIN、超时、返回和跨应用行为的实板回归。

实板暴露出普通 Android 设置 Intent 与 TV 系统的差异：当前系统没有标准
显示和无线网络入口。第三版先检查目标是否存在，显示入口退回系统实际
提供的“显示和声音”合并页，网络退回 TV Network；仍无目标时才进入系统
设置首页。我已经验证声音、显示和网络都能打开对应页面。

## 我从这次重构得到的经验

电视界面的品质首先来自信息层次和操作反馈。真实应用横幅、明确的继续
播放目标、可辨认的焦点，比在每张卡片上增加一句说明更有帮助。设计必须
按观看距离和实际密度检查，不能把手机式按钮放大后就算电视界面。

同时，视觉重构需要明确的业务边界：频道身份、播放路线、家长退出和
维护确认都要保留独立检查。漂亮截图、成功安装和连续操作可靠是三种
不同证据，我需要逐项取得后再宣布这一轮完成。
